# 中学1年 理科・数学 学習データベース

中学1年生の理科・数学を、学習・復習・小テスト・Webアプリ連携に使いやすい構造化データとして保存するリポジトリです。

## 収録内容
- `data/science.json`：理科の重要知識・公式・実験の考え方・確認問題・解答と解説
- `data/math.json`：数学の重要知識・公式・例題・練習問題・解答と解説
- `data/manifest.json`：データセットの説明、収録単元、形式バージョン
- `schema/knowledge-item.schema.json`：知識項目のJSON Schema
- `docs/USAGE.md`：利用方法、検索例、拡張方針

## 対象範囲
日本の中学校学習指導要領を意識した中学1年相当の主要単元を扱います。教科書会社や学校によって単元の順序・扱う深さが異なるため、単元の網羅性を確認しながら拡張する前提です。「全知識」を一度の作成で完全保証するものではなく、基礎を広く収録し、改善を重ねる学習データベースとして設計しています。

## データ設計
各知識項目は `id`、`subject`、`unit`、`topic`、`type`、`summary`、`details`、`keywords`、`questions` を持ちます。問題には `prompt`、`answer`、`explanation`、`difficulty`、`tags` を持たせ、答えだけでなく考え方も確認できます。

## ライセンス・利用上の注意
説明文と問題は学習用に独自作成したものです。教科書の文章や市販問題集の問題文をそのまま複製することを目的としていません。計算や実験の条件は、実際の授業・教科書に合わせて確認してください。
